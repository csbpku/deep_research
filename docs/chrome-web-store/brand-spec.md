# Reader 商店素材

沿用现有已验收的 Reader 品牌，不重做插件布局：深色圆角方块中的白色 R、白色阅读界面、蓝色证据链接、中性色输入区。图标 SVG 位于 `apps/extension/assets/icon.svg`，PNG 由该矢量源按 16/32/48/128 尺寸渲染。128px 图标保留 16px 透明边距。

色彩源：`apps/extension/reader-ui.css`。墨色 `#202735`，强调 `#3159c9`，纸张 `#ffffff`，辅助 `#667085`，细线 `#e3e6eb`。素材使用相同系统字体与简体中文，无外部字体、品牌 logo 或用户浏览器截图。

截图包含实际构建的扩展 UI：通过页面提取、选段、模型接口和问答/翻译任务生成，未手绘聊天控件。文章和模型响应为专门编写的可公开演示内容，不来自真实用户记录，也不作为真实模型速度、准确率或线上效果证据。展示页面标明“演示文章 / 示例回答”。原始截图与生成报告由捕获脚本保存；最终商店截图为 1280×800，小宣传图为 440×280。

截图主题：围绕原文提问与证据回链；逐段翻译与原文切换；可选模型服务与本地数据控制。宣传图强调 Reader 品牌，不增加不存在的功能或“零留存”“零权限”“自动适配所有网页”等承诺。
