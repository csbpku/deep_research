# Reader 商店素材

沿用现有已验收的 Reader 品牌，不重做插件布局：深色圆角方块中的白色 R、白色阅读界面、蓝色证据链接、中性色输入区。图标 SVG 位于 `apps/extension/assets/icon.svg`，PNG 由该矢量源按 16/32/48/128 尺寸渲染。128px 图标保留 16px 透明边距。

色彩与字体源：`packages/design-system/src/tokens.json`。墨色 `#20242c`，强调 `#405c9d`，纸张 `#ffffff`，辅助 `#626c7a`，细线 `#e1e5eb`。扩展内界面使用共享MUI主题，素材外框也读取同一套token。原网站保留自己的排版。界面中的服务商品牌图标来自随扩展打包的资源及其许可。

截图必须包含实际构建的扩展 UI：通过页面提取、选段、模型接口和问答/翻译任务生成，不手绘聊天控件、不替换回答或移除失败提示。新版素材读取公开 MDN 真实文章，调用实际模型，分别制作中文、英文界面及回答；中文素材演示英译中，英文素材演示中译英。标题、说明和宣传图也分别本地化，原文引文保留来源语言。页面与结果只证明本次实际操作，不代表全部模型或网站的准确率、速度。

MDN文章正文采用 CC BY-SA 2.5；画面标出来源 URL、MDN Web Docs 与许可，素材 README 保留原文和许可链接。包含 MDN 正文的截图改编依相同许可分享，Reader UI 与第三方标志保留各自权利。真实网页直接加载，不把下载的文章改写成自制页面。

截图主题：围绕原文提问与证据回链；逐段翻译与原文切换；可选模型服务与本地数据控制。宣传图强调 Reader 品牌，不增加不存在的功能或“零留存”“零权限”“自动适配所有网页”等承诺。

`capture-real-articles.mjs` 用于真实文章双语素材；`capture-assets.mjs` 保留为自制文章和确定性响应的旧演示工具，不能将其结果称为真实模型素材。每次捕获写入新建的版本目录，保留旧素材。`READER_STORE_BUILD_DIR` 指定待上传ZIP对应的解压目录，`READER_STORE_ASSETS_ROOT` 指定交付目录，`READER_LIVE_MODEL` 显式选择实际模型。报告记录来源、构建路径、隔离扩展ID、真实回答/译文、图片尺寸和SHA-256；权限只加入隔离副本，不写回上传包。生成后逐张检查六张截图及两张宣传图，不能仅凭脚本退出成功判断画面内容可用。
