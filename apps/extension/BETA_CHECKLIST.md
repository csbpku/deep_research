# 独立 Reader Beta 交付检查表

商店发布暂缓。这个清单用于把 ZIP 交给个人或小团队测试，不代表已经发布到 Chrome Web Store。

## 交付前

- [x] 使用 `npm run build` 和 `npm run package` 生成生产目录与 ZIP（2026-09-21 已复验）。
- [x] 确认生产 manifest 的 `host_permissions` 为空，只保留可选 HTTP(S) 内容权限；`tabs` 仅用于读取当前标签页元信息（2026-09-22 已复验）。
- [x] 阅读 [PRIVACY.md](./PRIVACY.md)，确认模型供应商的数据保留政策已向试用者说明。
- [x] 阅读 [COMPATIBILITY.md](./COMPATIBILITY.md)，明确当前页面类型和退化边界。
- [x] 不把 API Key、真实网页正文或图片放入测试报告、导出包或 issue；自动化输出已复核。
- [x] 独立模式不要求平台账号；平台模式作为显式可选层，通过 PKCE 连接，且不改变独立安装、BYO 模型、本地 IndexedDB 和导入导出路径。
- [x] 平台数据边界已验收：会话与确认结论可入库，网页全文档案、图片字节、翻译缓存和 API Key 不进入平台数据库。
- [x] 图片定位规则已覆盖“可靠坐标原位覆盖、图表纵轴纵向排版、低置信度原图旁译”三条路径；`npm run e2e:image-position` 使用隔离 headless Chrome 验证译文不覆盖不安全区域。

## 试用者路径

1. 在 `chrome://extensions` 开启开发者模式，加载 `.output/chrome-mv3`，或使用 ZIP 解压目录。
2. 打开公开技术文章、官方文档、GitHub README 或 Zread 小节，点击 Reader 扩展按钮。
3. 在侧栏选择模型服务商，填写一个模型和 API Key，确认连接和视觉检查通过。
4. 在当前页面选择目标语言，点击“全文翻译”，检查正文、代码、图片覆盖、进度、失败重试和“恢复原文”。
5. 选择一段文字完成解读、连续追问和收藏；关闭侧栏后重新打开，确认阅读会话仍在。
6. 可选：切换平台模式，连接 Deep Research，验证平台技术问答、会话同步、结论入库和断开连接；随后切回独立模式，确认本地阅读仍可继续。

## 需要记录的结果

- 读懂一个指定技术问题的时间，以及答案是否能指出原文证据、适用条件和未知项。
- 图片文字是否漏译、错译、坐标错配或遮挡箭头；低置信度是否明确退化。
- 数日后能否恢复讨论并复用收藏结论。
- 每篇页面的模型请求成本、图片延迟、失败重试次数和兼容性问题。

## 明确不属于本轮交付

不发布 Chrome Web Store，不承诺 PDF、全仓库理解、代码执行、团队实时共批注、后台全站抓取或官方托管模型。3–5 名开发者对照试用需要真实参与者和独立记录，不能由自动化脚本代替。
