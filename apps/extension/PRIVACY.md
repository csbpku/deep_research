# Deep Research Reader 隐私边界

本扩展默认独立运行，不要求 Deep Research 账号、雷达或数据库。它只在用户点击扩展按钮并主动开启阅读操作后，处理当前标签页中可见且已加载的公开正文、用户选择的文字和正文图片。

## 数据流

- 正文翻译、图片文字识别、图示解读和追问会直接发送到用户在设置中选择的模型服务；服务可以使用 OpenAI-compatible `/chat/completions` 或 Anthropic-compatible `/messages`。Anthropic 图片会先在扩展内转成 base64，再发送到其 `/messages` 接口。
- API Key 只保存在扩展自己的本地 IndexedDB 设置中，不写入网页、普通日志、导出文件或平台接口。扩展不声称提供操作系统密钥链级别保护。
- 阅读会话、滚动位置、讨论、标注和收藏默认保存在本地 IndexedDB。全文正文和图片翻译只保留在有界的临时任务输入与翻译缓存中，不作为永久全文档案。
- 用户可以显式切换到平台模式并连接 Deep Research。技术问答会把当前 URL、标题以及用户选择的选段、所在小节或有界页面正文发送给平台模型；会话同步只写入 URL、标题、页面版本、选区、讨论、当前回答和滚动位置。
- 只有用户确认保存的摘录、笔记、AI 结论、标签和来源会写入平台研究库。网页全文档案、图片字节、全文翻译缓存和 API Key 不会通过阅读同步接口保存到平台数据库。
- 断开平台后令牌会在服务端撤销并从扩展本地清除；本地 IndexedDB 中已有的独立阅读成果不会被删除。
- 模型供应商可能按照其自己的数据保留政策处理请求。扩展不承诺供应商端零留存；使用自建模型服务时应由用户配置该服务的数据策略。

## 采集边界

扩展不会主动读取密码、Cookie、表单输入或 `contenteditable` 内容，也不会自动翻页、后台抓取全站或执行网页内容中的工具指令。跨域模型和图片站点权限只在用户操作触发时按需申请；拒绝权限会显示可重试的失败状态。

网页正文被视为不可信资料。它只能作为翻译、讨论和引用证据，不能改变扩展任务、权限或工具调用。

## 用户控制

用户可以清除翻译缓存、删除本地阅读成果、导出和导入本地数据。导出文件会移除 API Key，并且不包含临时任务输入。卸载扩展前请先导出需要保留的成果；首版不保证卸载后的自动恢复。

## 权限

生产构建声明 `activeTab`、`scripting`、`tabs`、`storage`、`unlimitedStorage`、`alarms` 和 `sidePanel`，没有固定站点 `host_permissions`。`tabs` 只用于在侧栏打开时识别当前标签页的 URL、标题和窗口，不会因此读取网页正文；正文注入仍需用户点击扩展按钮，或确认当前 HTTP(S) 站点的可选权限。模型和图片站点使用可选的 HTTP(S) 权限，且只在用户配置或开启相关处理时申请。

如需报告隐私或数据问题，请在交付给团队前附上扩展版本、模型服务地址类型（不要附 API Key）、页面 URL 和复现步骤。
