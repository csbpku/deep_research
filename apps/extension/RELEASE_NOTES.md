# Reader 更新日志

记录 Reader 扩展每个版本的用户可见变更。Beta 发布记录见 [GitHub Releases](https://github.com/csbpku/deep_research/releases)；商店现状以 [Chrome Web Store](https://chromewebstore.google.com/detail/bldpmkepljipbadeegednfinnilgoedl) 为准。

版本号以 `apps/extension/package.json`、`apps/extension/manifest.json` 和
`apps/extension/wxt.config.ts` 三处为准，必须一致。CI 比较已发布的同版本 Beta
安装包内容：内容不同时拒绝覆盖；尚未发布的版本可以继续修订后再提交审核。

## 发布批次策略

商店审核是逐个版本的固定成本，因此不逐个小功能提交。做法是：功能合入
`main` 后先记在本文件，等攒够一批有用户价值的变更再提升版本号、打商店包并
提交审核。合入 `main` 只影响平台和 Beta Release，不影响已安装的商店版本。

## 0.2.37

状态：发布准备中；尚未发布 Beta 或提交 Chrome Web Store 审核。

- 首次运行：空状态拆成「本机模型」和「自己的模型服务」两条路径，并新增“检测本机模型”。
  本机已运行 Ollama、LM Studio 或本地 API 代理时，一次点击即可检测并直接保存配置，不需要 API Key。
- 首次运行：还没有聊天记录时不再显示空的“查看聊天记录”入口；空状态说明改为“Reader 不自带模型”，不再要求用户先理解独立模式。
- 设置：保存与测试按钮固定在模型设置底部，窄侧栏里也不会被推到首屏之外。
- 网页浮层：右侧快捷入口可以收起，只保留「打开聊天」；收起状态会记住，鼠标移入或键盘聚焦时再展开。
- 网页浮层：图片上的“原图 / 放大 / 解读”改为悬停或聚焦时出现在图片上方，不再压住图表标签。
- 选段翻译：浮层高度跟随译文长度，并优先放在选区右侧、左侧、下方或上方，避免遮住所选原文。
- 外观：新增浅色 / 深色 / 跟随系统，侧栏、历史页和网页内的阅读控件使用同一套共享配色。
- 收藏：可按标签筛选（标签项带数量，可与关键词和类型叠加），并支持一键导出 Markdown，按页面分组保留引文、笔记、AI 结论、标签和来源。
- 回答：证据卡可展开长引文、单独复制引文；“复制回答”改为带引用的 Markdown；证据区上方显示覆盖了多少段原文，正文被截取时明确提示。
- 联网补充：Brave 与 Bing 并行请求、7 秒总预算、先返回者优先；解析容忍嵌套标签与实体，来源 URL 去掉追踪参数后去重，中文问题按片段匹配。

## 0.2.32

Beta：2026-10-29 发布 `reader-v0.2.32`。

- 选段解释：等待侧栏加载模型和平台配置后再执行选段动作，点击“解释这段”会打开聊天并自动发问；请求失败后仍保留问题。
- 原文定位：跨段选择保留与正文位置一致的原文换行和空白，修复平台锚点校验失败。
- 错误提示：区分选段校验失败与平台登录失效，并保留请求编号供排查。
- 选段翻译浮窗：设置位置和缩放尺寸后保留主题颜色，恢复不透明背景、边框与清晰文字。
- 输入区：选段预览可压缩并滚动，小窗口内仍支持拖动、键盘和按钮调节输入框高度。
- 保存：合并标注与摘录入口，一条记录同时保存原文、笔记和可选高亮，并可选择附带 AI 解读和同步研究库；旧标注仍保留，编辑时转为统一记录。
- 模型配置：模型选择改为可展开、搜索和键盘操作的列表；重开设置时在已授权范围内刷新完整模型清单，补充分页读取与读取失败提示。
- 服务商选择：修复菜单无法滚动和名称/副标题挤在同一行；增加 Mistral AI、Together AI、NVIDIA、阶跃星辰，MiniMax 合并为一个入口并单独选择国内/国际区域，兼容旧配置。
- 浮动入口：点击“打开聊天”后按侧栏打开结果结束提示；失败或超时显示浏览器工具栏重试指引，提示自动收起，迟到的打开结果不会覆盖新的任务进度。
- 窄侧栏：模型与阅读范围分行显示，避免英文选段状态下模型名被挤没。
- 阅读面板：细化原文标题层级、选段操作的图标间距与关闭按钮，优化空状态文字换行。
- 设置与历史：简化设置标题层级，统一状态标签对齐、历史计数和清除搜索图标。
- 英文界面：补齐本页保存内容的标题翻译。
- 收藏：完整列表新增关键词搜索、类型筛选、总数和分页，不再仅显示每类最近 12 条；关键词覆盖原文、笔记、AI 结论、标签与来源地址。尚未并入统一记录的标注仍可编辑。
- 删除：收藏删除前显示条目确认，删除后可在当前面板关闭前逐次撤销；已在其他页面恢复的内容不会被旧快照覆盖。
- 总结：首问按钮随阅读范围显示“文章讲了什么？”或“这段讲了什么？”，图示范围下隐藏文字总结入口。
- 首次配置：模型连接与保存步骤提前，语言偏好后移，平台数据使用细节按需展开。

## 0.2.29

已合入 `main`（`d2ea516`），已发布 Beta 0.2.29。

包含两批功能：

- 联网搜索（PR #12）：阅读聊天新增可选的联网检索开关。默认关闭，打开后可让模型
  检索当前原文之外的信息，回答仍标注哪些内容来自原文、哪些来自检索结果。
- 翻译提速（PR #13）：
  - 长文首批缩小以提前显示，后续批次按最多 24 块、约 3,000 字符处理，减少往返次数。
  - 平台翻译请求并发从 3 提升到 6，与 Web BFF 上限和 AI engine 的 LLM 信号量对齐。
  - 引擎侧可重试的供应商失败（429/529/超时）先等待抖动指数退避再重试。
  - 独立模式沿用平台对 MiniMax M3.1 的低推理档策略，翻译延迟明显下降。
  - 平台模式不再因为单个批次缺项就重译整段，只补译缺失或冲突的块。

生产链路实测（部署后，交错重复两轮）：287 块、41,215 字符的文章，
翻译墙钟从约 119 秒降到约 50 秒，覆盖 287/287，无未翻译块、零失败。
