# Deep Research Reader 兼容矩阵

## 当前验收目标

首版验收目标是桌面 Chrome 116+。Edge 作为兼容验证对象；Firefox、Safari、PDF、视频字幕、内网页面和复杂跨域 iframe 不在首版承诺内。

| 页面类型 | 首版行为 | 已验证范围 | 主要退化方式 |
| --- | --- | --- | --- |
| 公开技术文章 | 正文块翻译、图片文字覆盖、选段讨论 | 本地模拟 6 页；真实公开页面由 `e2e:live` 记录 | 动态组件或封闭 Shadow DOM 退化为选段操作 |
| 官方文档 | 同上，保留目录、代码和链接 | 本地模拟 6 页；真实公开页面由 `e2e:live` 记录 | 懒加载正文在加载后重试 |
| GitHub 当前 README/文档 | GitHub 容器适配、代码保留、当前页理解 | 本地模拟 6 页；真实公开页面按网络可达性记录 | 不声称理解整个仓库、全部 Wiki 或未打开文件 |
| Zread 当前小节 | 当前小节正文、图片和选段讨论 | 本地模拟 6 页；真实公开页面按网络可达性记录 | 不声称理解整个仓库或未打开小节 |

## 已通过的本地浏览器门槛

- 24 个页面：文章、文档、GitHub、Zread 各 6 页。
- 30 张模拟技术图，验证原位覆盖、原图恢复、代码保留、链接保留和动态正文。
- Worker 侧栏关闭恢复、Chrome 完全重启恢复、暂停、取消、单项重试和本地导入导出。
- 引用定位覆盖未修改正文成功、重复文本拒绝和内容 hash 漂移拒绝。

运行矩阵：

```bash
READER_E2E_MATRIX=1 npm run build:e2e
npm run e2e:matrix
```

本地矩阵不等于所有真实网站都兼容。真实网站需要单独记录导航失败、正文是否加载、图片权限和页面版本；不能把网络超时当作插件通过或失败。

## 已知边界

- Canvas、封闭 Shadow DOM、复杂跨域 iframe 和未加载图片不会被伪装成已翻译。
- 图片识别置信度低于 `0.75` 时不覆盖原文：有 OCR 坐标的译文锚定在对应原文框旁边，没有可用坐标才显示整图旁侧说明；如果图片左右都没有空间，区域译文放在图片外部下方并保留锚点，不覆盖原图。只有达到门槛且坐标全部在原图范围内才允许原位覆盖。视觉模型不可用时保留原图并继续正文翻译。
- GIF/APNG 等可能包含动画的图片默认显示边界；只有用户在原网页图片控制条确认“当前帧”后，才允许按该静态帧处理。
- 模型服务的 CORS、限流和视觉能力由用户配置的服务决定；设置页会做连接和视觉标记检查。独立模式支持 OpenAI-compatible `/chat/completions` 和 Anthropic-compatible `/messages` 两种协议。
- 页面内容变化会使旧证据失效；无法唯一定位时扩展不会跳转到相似段落。
