# Deep Research Reader 独立 Beta

这是一个可完全独立安装的 Chrome 扩展试用版。它在原网页中提供全文翻译、图片文字翻译、技术解读、连续追问、引用回跳和本地收藏；有 Deep Research 账号时，还可以选择平台模式，把有界会话和确认过的结论同步到调研平台。平台连接不是安装或使用独立模式的前置条件。

## 安装

1. 解压 `deep-research-reader-beta-0.2.3.zip`。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录（目录根部应直接包含 `manifest.json`）。
4. 打开公开技术文章、官方文档、GitHub README 或 Zread 小节，点击工具栏中的 Reader 图标。
5. 在侧栏“我的阅读”点击“打开历史页”，可以搜索、重命名、删除或分别导出聊天会话和知识结论。

插件采用安全的两级启动：首次点击 Reader 只启用当前标签页；在同一个阅读窗口切换到新站点时，侧栏会先显示“启用此站点”，用户明确点击后才申请该站点权限。不会在后台静默读取新网页，也不会默认申请所有网站权限。

## 配置自己的模型

在侧栏点击“设置”，填写：

- 模型服务商（OpenAI、Anthropic、MiniMax、DeepSeek，或其他 OpenAI-compatible / Anthropic-compatible 服务）；
- 一个模型名称；文本、图片翻译和图示解读共用这个模型；
- API Key；
- 翻译目标语言在当前页面的“全文翻译”旁选择，不保存在模型配置中。

点击“保存并测试连接”。模型请求直接从扩展发送到所选服务商；选择其他 OpenAI-compatible 或 Anthropic-compatible 服务时再填写自定义接口地址。模型服务需要允许扩展页面的 CORS 请求；扩展会在用户操作时按需申请服务域名权限。Anthropic 预置和自定义 Anthropic-compatible 服务都使用 Messages API。

## 数据在哪里

- API Key、阅读会话、讨论、标注、收藏和有界翻译缓存保存在当前浏览器的本地存储中。
- API Key 不会进入任何平台、网页、普通日志或导出 JSON；扩展不声称提供操作系统密钥链级保护。
- 独立模式不会连接 Deep Research。平台模式只在用户主动发起技术问答、同步会话或确认保存结论时发送对应的有界数据。
- 平台数据库不保存网页全文档案、图片字节、全文翻译缓存或 API Key；确认保存的摘录、笔记、AI 结论和来源会进入研究库。
- 卸载前请先使用“导出阅读数据”。

## 试用重点

1. 点击“全文翻译”，检查正文、代码块保护、图片进度、原图恢复和失败重试。
2. 选择一段文字，测试翻译、解读、追问、引用回跳和收藏。
3. 关闭侧栏后重新打开，确认翻译任务和讨论仍能继续。
4. 图片坐标、数字、箭头或文字过密时，检查译文是否锚定在对应原文旁边；完全无法定位时才接受整图旁侧说明，视觉模型不可用时保留原图并继续正文翻译，不要把安全退化当成失败。

## 当前边界

首版目标是桌面 Chrome。PDF、视频字幕、全仓库理解、代码执行、团队实时批注、内网页面和复杂跨域 iframe 不在本 Beta 承诺内。动画图片需要用户确认静态帧；无法安全读取或定位的图片会显示可见失败，不会伪造原位覆盖。详见 `COMPATIBILITY.md` 和 `PRIVACY.md`。
