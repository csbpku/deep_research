# Provider icons

Brand SVG files are from [Lobe Icons](https://github.com/lobehub/lobe-icons),
commit `05a9b8c41e4735a4a2b6d2f1e43574bd8ec6c8cb`,
under `packages/static-svg/icons/`. The repository's MIT license is preserved in
`LICENSE.txt`. Logos identify the corresponding supported service.

`local-api.svg` and `custom-api.svg` are generic interface symbols authored for
Reader; they do not represent a third-party brand.

All icons are packaged locally. No external image, script or font request is
needed to display this picker.
